# PMA 物业管理系统

基于 Python Tkinter 和 SQLite 的单机桌面物业管理系统，实现集中式账号创建和基于角色的访问控制。

## 运行环境

- Python 3.10 或更新版本，需包含 Tkinter（Windows 官方 Python 安装程序默认提供）
- 无需安装第三方 Python 包

## 启动

Windows 双击 `start.bat`，或在项目目录打开终端执行：

```bash
python app.py
```

首次启动设置超级管理员。随后选择“超级管理员”登录，新增房屋，再创建员工和业主账号。新账号首次登录必须修改密码。

## 功能

- 集中创建账号，没有公开注册入口
- 手动选择角色，服务层校验角色权限
- 首次改密、连续五次密码错误锁定、管理员解锁和重置密码
- 超级管理员、物业主管、财务专员、业主四种工作台
- 房屋档案、费用账单、报修工单和登录审计
- 业主仅访问绑定房屋的数据

## 文件结构

```text
app.py           桌面界面、业务服务和数据库初始化
test_system.py   认证、权限、业务及页面构建测试
start.bat        Windows 启动脚本
使用说明.md       详细说明及适用范围
data/            运行时数据库（自动生成，不提交到 Git）
```

## 测试

```bash
python test_system.py
```

测试使用内存数据库，不修改实际业务数据。页面构建测试需要桌面环境。

## 数据与范围

数据保存在 `data/pma.sqlite3`。本项目为单机基础版，不含网络服务端和在线支付。不要把实际账号数据库、密码或个人资料提交到代码仓库。详细流程见 [使用说明](使用说明.md)。
